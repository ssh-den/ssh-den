## Featured projects

### [Moonlight Voice](https://github.com/ssh-den/moonlight-voice)
`JavaScript` `HTML/CSS` `Python` `Home Assistant`

A local audio response service for Home Assistant. Includes a web UI I built with vanilla JavaScript, HTML, and CSS, served through authenticated Ingress.

Handles audio playback through an OpenAI-compatible TTS endpoint or Home Assistant's native TTS platform.

### [PadRelay](https://github.com/ssh-den/PadRelay)
`Python` `Networking` `Low Latency` `Protocol Design`

Stream gamepad input between computers. Captures controller input across operating systems and emulates an Xbox 360 or DualShock 4 controller on a remote Windows PC.

Supports TLS, TCP/UDP, challenge-response authentication, heartbeats, and rate limiting.

Available on [PyPI](https://pypi.org/project/padrelay/).
